# AI 开单 EA｜前期设计包

本目录根据 5 张参考图整理，目标是先固定产品边界、EA/API 协作方式与前端信息架构，再进入真实行情和交易接口开发。

## 文件导航

- `docs/01-EA开发需求设计.md`：业务目标、角色、开关单状态机、风险规则、异常与验收标准。
- `docs/02-前端页面设计.md`：总览、行情、决策、复盘、风控五个页面的内容和交互说明。
- `docs/03-技术栈与架构.md`：生产技术栈、服务边界、部署拓扑、安全与可观测性。
- `docs/04-API接口草案.md`：EA、分析服务、前端之间的 REST/WebSocket 协议草案。
- `docs/05-开发计划与测试.md`：分期交付、测试矩阵与上线门槛。
- `前端原型/index.html`：可直接打开的总览页；顶部导航可进入其余四页。

## 查看 HTML 原型

可直接双击 `前端原型/index.html`。若浏览器限制本地脚本，可在 `前端原型` 目录启动静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/`。

## 当前阶段的重要约定

1. 原型中的账户、价格、新闻和统计数字都是演示数据，不连接真实交易账户。
2. 第一阶段支持 MT5，协议与后端保持 MT4 可兼容；是否同时交付 MT4 在开发启动前确认。
3. AI 只生成“交易计划”，EA 是唯一能向交易终端发单的组件，且必须通过本地硬风控。
4. 实盘前必须依次通过回放、策略测试器、模拟盘和小资金灰度；不得从原型直接跳到实盘。
