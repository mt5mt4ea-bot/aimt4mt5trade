# WiseFX AI v1.1 官网与 RBAC 设计

## 页面流程

1. 未登录访问 `https://ai.mt4mt5.trade`，展示产品首页、核心能力、安全机制和计划价格。
2. 用户可以登录或注册；开发演示阶段默认填入管理员演示账号，并提供会员账号快捷切换。
3. 登录成功后，同一页面切换到交易控制台。
4. ADMIN 角色显示“用户管理”入口，MEMBER 仅显示交易工作区。
5. 退出登录后销毁服务端会话并返回官网首页。

## RBAC 模型

RBAC 数据由 `users`、`roles`、`permissions`、`user_roles` 和 `role_permissions` 五组关系组成。接口检查 permission code，不直接依赖前端展示或角色名称。

| 权限 | ADMIN | MEMBER | 用途 |
|---|---:|---:|---|
| `dashboard.view` | 是 | 是 | 查看账户、行情、AI决策与风控信息 |
| `trading.control` | 是 | 否 | 修改服务端自动交易开关 |
| `users.manage` | 是 | 否 | 查看会员、修改角色和启停账户 |
| `system.manage` | 是 | 否 | 后续系统配置管理预留 |

## 会话安全

- 密码使用 PBKDF2-SHA256 和独立随机盐存储。
- 登录会话使用随机令牌；数据库只保存令牌的 SHA-256 摘要。
- 浏览器 Cookie 设置为 `HttpOnly`、`SameSite=Lax`，HTTPS 访问时设置 `Secure`。
- 所有敏感写操作验证会话权限和 `X-CSRF-Token`。
- 停用用户时立即删除该用户全部会话。
- 管理员不能在后台降级或停用自己的账户，避免意外锁死。

## 演示与生产边界

演示账号只用于 v1.1 开发预览。正式商业运营前必须关闭 `DEMO_AUTH_ENABLED`，删除演示用户，增加邮箱验证、密码重置、登录限流、验证码、操作审计和首个管理员安全初始化流程。
